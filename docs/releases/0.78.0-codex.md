# soundLAB web 0.78.0 integration

Status: review candidate; publishing main requires contributor cross-review and CI. The existing web/PWA/Windows/Android live-site channel is the intended destination. There is no new native package, release signing, firmware update or hardware configuration in this change.

## Behavior

- MIDI Hub adds play, CC/program controls, transformation rules, explicit SysEx tools and decoded monitoring under Keys. Missing selected ports stay disconnected. Thru is session-only and stops on lifecycle/routing changes; tracked notes release to their original destination.
- LUMI Practice separates a selected MODX answer input from a LUMI-named display output. Simulation is labeled; real output starts off and requires a transient test followed by arming. The 24-key window, held notes and cleanup are bounded. Hardware lighting is experimental.
- Score Preview reads a documented single-part MusicXML subset, renders a simplified staff and exact event table, plays through the app master, preserves original imported bytes and exports MIDI. Unsupported structures are rejected. PDF/photo/audio recognition is unavailable.
- Music Library stores immutable original PDF/raster images/MusicXML/MXL/MIDI and explicit metadata in browser-local IndexedDB. Actual supported XML checks append MIDI versions; backup ZIP packages include original bytes, available outputs and an integrity-checked manifest. Imported validation claims are downgraded until local checking. Cross-tab limits and revision checks are transactional. Preview is not recognition; storage is not synced, encrypted or protected from browser clearing/eviction. Backups are user-controlled downloads.
- Helix Stadium XL exposes only the documented v1.4 preset, snapshot and tap subset after explicit firmware selection/output arming. Firmware unknown/older is disabled. No patch uploads, Showcase, amp/cab/IR or audio routing changes.
- What's New is nonblocking, dismissible per minor version and always available in Settings. Offline assets cover the new tools; activation removes only old soundLAB caches.

See [MIDI Hub](../MIDI-HUB.md), [LUMI](../LUMI-PRACTICE.md), [Score](../SCORE.md) and [Helix](../HELIX-STADIUM.md) for actual scope and platform limits.

## Verification and remaining gates

All 17 suites for the first integrated candidate passed locally. The exhaustive tap suite initially reached the local helper's three-minute process limit; it then passed its unchanged assertions with a longer process allowance. Focused final-library integration checks also cover actual navigation and offline reload. Independent peer review identified and owners corrected malformed MusicXML pitch acceptance, non-LUMI ROLI output matching, quiz timing behind release history, scoped cache lookup and transactional library capacity. The exact final head and completed CI results belong to the PR. PR validation uses an isolated Playwright dependency and the runner's installed Chrome, without credentials or hardware.

No real MIDI device was opened or sent commands. Physical LUMI lights, MODX response, Helix firmware behavior, latency and native-wrapper independent routing remain unverified. These limits must stay visible; mock ports are not hardware evidence. No Pi access is authorized. Contributor approval and successful CI remain release gates despite the deadline.
