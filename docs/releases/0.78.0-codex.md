# soundLAB web 0.78.0 integration

Status: review candidate; publishing main requires contributor cross-review and CI. The existing web/PWA/Windows/Android live-site channel is the intended destination. There is no new native package, release signing, firmware update or hardware configuration in this change.

## Behavior

- MIDI Hub adds play, CC/program controls, transformation rules, explicit SysEx tools and decoded monitoring under Keys. Missing selected ports stay disconnected. Thru is session-only and stops on lifecycle/routing changes; tracked notes release to their original destination.
- LUMI Practice separates a selected MODX answer input from a LUMI-named display output. Simulation is labeled; real output starts off and requires a transient test followed by arming. The 24-key window, held notes and cleanup are bounded. Hardware lighting is experimental.
- Score Preview reads a documented single-part MusicXML subset, renders a simplified staff and exact event table, plays through the app master, preserves original imported bytes and exports MIDI. Unsupported structures are rejected. PDF/photo/audio recognition is unavailable.
- Helix Stadium XL exposes only the documented v1.4 preset, snapshot and tap subset after explicit firmware selection/output arming. Firmware unknown/older is disabled. No patch uploads, Showcase, amp/cab/IR or audio routing changes.
- What's New is nonblocking, dismissible per minor version and always available in Settings. Offline assets cover the new tools; activation removes only old soundLAB caches.

See [MIDI Hub](../MIDI-HUB.md), [LUMI](../LUMI-PRACTICE.md), [Score](../SCORE.md) and [Helix](../HELIX-STADIUM.md) for actual scope and platform limits.
