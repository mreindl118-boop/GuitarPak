# soundLAB 1.1.0

Learn, Free Play, Library and Progress organize practice around the selected
instrument. Existing tools, saved routes and Studio remain reachable. A global
Tuner opens from every tab without starting the microphone; Start listening is
deliberate and shares the configured audio input safely.

The local song library retains original PDFs, images, MIDI and MusicXML across
ordinary app updates. Review editable notes/chords/rests beside the source,
save versions and named sections, select target parts and use the existing
Wait for Me or Play at Tempo player. Resume restores the section/setup for a
new attempt. Musical input and instrument XP remain independent of source
instrumentation; imports and reviews earn no XP.

Settings recovery now acknowledges writes, retains unknown/legacy values and
offers reviewed backup imports, rollback, sampler-file export and visible
unsaved-data recovery. The song library has a separate full archive. App
updates checkpoint practice and drafts before a deliberate reload. Editable
teacher-text plans produce short actionable steps using actual app tools.

**Notation recognition beta** reads one selected monophonic treble or bass staff
on one page at a time, from a clear engraved PDF or image. It creates a local,
source-linked draft with retained model evidence. Compare every pitch, rest and
duration with the original, correct mistakes and explicitly review before
practice. This is not full piano, polyphonic, multistaff, scanned-score or whole
multipage recognition. Repeats can be omitted without warning. It works offline
after approximately 21 MB of bundled model/runtime assets are cached. See
[the recognition workflow and limits](https://github.com/mreindl118-boop/GuitarPak/blob/v1.1.0/docs/LOCAL-RECOGNITION.md).
Unknown or unconfirmed rhythm uses Wait-only practice. Unsupported MusicXML and audio
chords are explained rather than graded as invented notes. No Google Docs connection, private-file upload,
cross-device sync or new APK is included. Same-origin browser storage can be
lost when site data is cleared or evicted. Physical MIDI/LUMI/audio behavior
remains unverified; cloud checks use synthetic inputs rather than physical devices.
